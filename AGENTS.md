# Project Operating Rules

This repository is the local working copy for the MEBA Teklif Sistemi.

## Default Work Rule

Unless the user explicitly asks otherwise, any work about this program must update the program files in this local repository as part of the task. Do not stop at advice or instructions when the requested change can be made safely in the workspace.

For every program-related task:

1. Treat this repo as the active local source of truth for development work.
2. Check Git status before changing files.
3. Pull or compare with GitHub when freshness matters, without overwriting local/user changes.
4. Make the necessary local file changes directly.
5. Run reasonable verification for the change.
6. Report any uncommitted changes and whether GitHub is ahead/behind.

## Naming Rule

Use these names unless the user requests a different naming scheme:

- GitHub repo: `Meba-Teklif-Sistemi`
- Local development folder: `Meba-Teklif-Sistemi`
- Local dev launcher: `MEBA Teklif - Guncel Baslat`
- Live/PWA launcher: `MEBA Teklif - Canli Sistem`
- Manual PDF archive: `MEBA Mekanik Teklifler - PDF Arsiv`

## Safety

Never delete, move, or rename user folders, archives, PDFs, or Git branches without a clear confirmation from the user. Prefer creating documented cleanup plans first, then apply them after approval.
